=== Building Architecture Documentation

Whenever you change the C4 model, AsciiDoc chapters, ADRs, or TDRs, rebuild the docs:

[source,bash]
----
arc42-c4 generate
----

This exports the Structurizr DSL to PlantUML, cleans stale diagram caches,
and renders the final HTML and PDF reports.

=== Adding New Documents

[source,bash]
----
# Add an Architecture Decision Record
arc42-c4 new adr "Use PostgreSQL as the operational database"

# Add a Technical Debt Record
arc42-c4 new tdr "Retry logic missing in payment service"

# Add a Data Card
arc42-c4 new data-card "Raw Events Dataset"

# Add a Model Card
arc42-c4 new model-card "Fraud Detection Classifier"

# Add a Runbook
arc42-c4 new runbook "Deploy to Production"

# Add a Guideline
arc42-c4 new guideline "REST API Design Standards"
----
